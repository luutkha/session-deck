# SessionDeck: start here (any agent)

Read `CLAUDE.md` first. It is the project's entry point for every agent, not only Claude, and lists what to read next and the standing rules.

Knowledge base:
1. `docs/DECISIONS.md`: the user's decisions and working rules. Do not undo them.
2. `HANDOFF.md`: one-page current state, known gaps, history.
3. `docs/IMPLEMENTATION.md`: how to build a change (workflow, checklists, test standard, definition of done).
4. `docs/FEATURES.md`: feature tree + matrices (rules, code path, tests per feature).
5. `docs/CODEMAP.md`: which folder and file does what.
6. `docs/LESSONS.md`: gotchas that already cost time, by topic.
7. `DESIGN.md` (Orca look), `README.md` (features, run, test). `PLAN.md` is historical.

If you were given a task brief, the brief's SCOPE wins: edit only the files it names, even where these docs suggest more.
