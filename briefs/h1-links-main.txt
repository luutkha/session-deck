SPEC:
1. linkText.ts (PURE, no fs): `parseLinkText(raw: string): ParsedLink | null` where ParsedLink = { kind: 'url'; url: string } | { kind: 'path'; path: string; line?: number; column?: number; home: boolean }. Steps: trim; reject empty, > 1024 chars, control chars (incl. NUL); strip wrapping quotes/backticks/angle brackets and ONE layer of surrounding () [] {}; strip trailing sentence punctuation (. , ; : ! ? ) ] } ' " ` >) repeatedly (but keep a trailing ')' when the text has an unmatched '(' before it, e.g. URLs like https://en.wikipedia.org/wiki/Foo_(bar)). URL: http://, https:// (case-insensitive) or mailto: -> kind url (normalize with `new URL`, reject on throw); `file:///C:/x/y` -> path 'C:/x/y' (decode %xx). Anything else with a scheme other than a Windows drive letter (javascript:, data:, ftp:, vbscript: ...) -> null. PATH forms: `C:\x\y`, `C:/x/y`, `\\server\share\x`, `~/x` or `~\x` (home=true, path without the ~), `./x`, `.\x`, `../x`, `src/a/b.ts`, `src\a\b.ts`, bare `package.json`/`README.md` (must contain a dot extension or a path separator, otherwise null: plain words like `hello` are NOT links), plus position suffixes `:12`, `:12:5`, `(12)`, `(12,5)` which are stripped into line/column (a drive-letter colon `C:` is not a position). Wildcards `*` `?` `|` `<` `>` and `"` inside the path -> null.
2. LinkService.ts: `createLinkService(deps)` with deps = { getSessionCwd(id): string | null; stat(path): Promise<{ isFile: boolean; isDirectory: boolean } | null> (null when missing); openPath(path): Promise<string> (Electron shell.openPath: '' on success, an error message otherwise); openExternal(url): Promise<void>; showItemInFolder(path): void; homedir(): string }. Methods: `resolve(sessionId, text): Promise<ResolvedLink | null>`: url -> {kind:'url', target}; path -> resolve against the session cwd (unknown session -> only absolute/home paths work), normalize with node:path.win32, `stat` it: directory -> kind 'folder', file -> kind 'file', missing -> null; keep line/column. `resolveMany(sessionId, texts)` -> array same length (max 200 texts, extra -> null; dedupe stat calls for identical texts). `open(sessionId, text, reveal): Promise<OpenLinkResult>`: re-resolves (never trusts the caller), url -> openExternal (only http/https/mailto, ever), folder -> openPath, file -> reveal ? showItemInFolder : openPath. SECURITY: a file whose extension is executable or script-like (.exe .com .bat .cmd .ps1 .psm1 .vbs .vbe .js .jse .wsf .wsh .msi .msp .scr .lnk .reg .hta .cpl .jar .dll .sh) is NEVER launched by a click: it is revealed in Explorer instead (ok:true, kind 'file'). Failures return { ok:false, error } with a short human message ("File not found", "Could not open: <os message>"), never throw.
