Rules: disabled -> no alerts (markers still tracked); per window, when usedPercentage >= criticalAtPercent and level < critical -> one 'critical' alert; else when >= warnAtPercent and level < warn -> one 'warn'; alerts fire ONCE per window instance (same resetsAt); when resetsAt changes (new window) or the percent drops back below warn after a larger value AND notifyOnReset -> one 'reset' alert (only if the previous marker had a non-none level or percent >= warnAtPercent, so a quiet window does not spam), then markers restart at none; a window whose usedPercentage is null/absent is skipped; first observation after app start with a percent already past the threshold alerts once (acceptable) unless a persisted marker for the same resetsAt says it was already alerted.
