FILES AND EXACT SIGNATURES (import types from '../../shared/types' and '../../shared/ipc'; Id = string):

src/renderer/state/selectors.ts
- export interface Section { readonly group: Group | null; readonly sessions: readonly Session[] }
- groupedSessions(data: StoreData): readonly Section[]   // one Section per group in data.groupOrder order (skip ids that do not exist), each group's sessions sorted by `order` ascending; the ungrouped bucket (group null, sessions with groupId null sorted by order) is ALWAYS LAST and is always present, even when empty.
- filterByStatus(sections: readonly Section[], statusIds: ReadonlySet<Id | null>): readonly Section[]   // empty set = return sections unchanged; otherwise keep only sessions whose statusId is in the set (null in the set matches sessions with no status); groups stay even if they end up empty.
- statusOf(data: StoreData, session: Session): StatusDef | null
- flatSessionIds(sections: readonly Section[]): readonly Id[]   // visible order for keyboard navigation: skips sessions inside COLLAPSED groups; ungrouped sessions always visible.
- countByStatus(data: StoreData): ReadonlyMap<Id | null, number>

src/renderer/state/dropTarget.ts
- export type DragItem = { readonly kind: 'session' | 'group'; readonly id: Id }
- export type DropOver = { readonly kind: 'session' | 'group' | 'ungrouped'; readonly id?: Id; readonly position: 'before' | 'after' | 'inside' }
- export type DropAction = { readonly type: 'moveSession'; readonly sessionId: Id; readonly groupId: Id | null; readonly index: number } | { readonly type: 'reorderGroups'; readonly order: readonly Id[] }
- computeDrop(drag: DragItem, over: DropOver, data: StoreData): DropAction | null
  Rules: session dropped on a group header with position 'inside' -> move to END of that group. Session dropped on another session 'before'/'after' -> that session's group, index = target's index (+1 for 'after') measured in the group's sorted list; when the dragged session is currently in the SAME group and its old index is lower than the computed index, subtract 1 (because it is removed first). Session dropped on 'ungrouped' (inside) -> end of the ungrouped list. Group dropped on a group 'before'/'after' -> reorderGroups with the full new order. Group dropped on anything else, session dropped on itself, no-op moves (result identical to current position), unknown ids -> return null.

src/renderer/Sidebar/inlineEditValidation.ts
- validateName(raw: string): { ok: true; value: string } | { ok: false; error: string }  // trims; empty -> error 'Name required'; longer than 100 chars -> error 'Name too long'.

src/renderer/state/useSessionStore.ts
- export function useSessionStore(): { data: StoreData | null; runtime: ReadonlyMap<Id, RuntimeState>; lastError: string | null; clearError(): void; actions: SessionActions }
- SessionActions has one async method per window.api call: createSession(input), renameSession(id,name), setSessionStatus(id,statusId), moveSession(id,groupId,index), removeSession(id), createGroup(name), renameGroup(id,name), removeGroup(id), setGroupCollapsed(id,collapsed), reorderGroups(order), upsertStatus(status), removeStatus(id), pickFolder().
- Loads once with window.api.getStore() (sets data + initial runtime map), then subscribes with window.api.onStoreChanged and window.api.onRuntime, unsubscribing in the effect cleanup. Every action wraps the api call in try/catch: on failure set lastError to the error message (never throw into render, never swallow silently). Use immutable updates (new Map for runtime).
- The hook must not import anything from 'electron'.
