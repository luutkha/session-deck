GOAL: Backend for SESSION SLEEP. A sleeping session has its Claude process stopped (frees memory/CPU) but keeps its card, tab, name, status and Claude conversation. Activating it later resumes the SAME conversation with `--resume` (this resume-on-activate path already exists). Sleep happens (a) automatically when a session has been idle for the configured time, (b) manually through IPC.

3. sleepPolicy.ts (PURE, tested): `pickSessionsToSleep(input): Id[]` with input { nowMs; settings: SleepSettings; activeSessionId: Id | null; sessions: readonly { id; closed: boolean }[]; runtime: ReadonlyMap<Id, RuntimeState>; lastTouchAt: ReadonlyMap<Id, number> }. A session is picked when: settings.enabled, not closed, runtime.run === 'running', not already sleeping, id !== activeSessionId, activity is NOT 'working' and NOT 'needs-input' (only 'finished' or unknown/absent), no attention pending (`attention === null`), and nowMs - max(lastTouchAt, activityAt ?? 0) >= afterMinutes * 60000 (afterMinutes clamped to MIN/MAX_SLEEP_MINUTES; a missing lastTouchAt counts as 'now' = not idle yet).
