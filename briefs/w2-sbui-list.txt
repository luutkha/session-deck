PUBLIC COMPONENT `Sidebar` (Sidebar.tsx), props:
{ data: StoreData; runtime: ReadonlyMap<Id, RuntimeState>; activeId: Id | null; onSelect(id: Id): void; actions: SessionActions; onNewSession(groupId?: Id | null): void; onEditStatuses(): void; lastError: string | null; clearError(): void }
- Header: title "Sessions", button "+ New session" (calls onNewSession()), button "+ Group" (creates a group named "New group" via actions.createGroup then puts its header into inline rename).
- StatusFilter chips: one per status plus "None", multi-select toggle, each shows its count (countByStatus). Selected set feeds filterByStatus.
- List: sections from groupedSessions(data) through filterByStatus. Group sections first, ungrouped bucket last (no header when it has no group; show a muted "Ungrouped" label only if at least one group exists).
- Footer: button "Statuses" (calls onEditStatuses).
- lastError banner at the top with a dismiss button (calls clearError).
- Keyboard (listener on the list container, focusable, roving selection): ArrowUp/ArrowDown move through flatSessionIds and call onSelect; Enter selects; F2 starts rename of the active session; Delete asks to remove it with the in-UI confirm; Ctrl+N calls onNewSession() (window-level listener registered while mounted, removed on unmount).

GroupSection.tsx: caret toggles collapse via actions.setGroupCollapsed, name (double-click or F2 on the focused header renames inline via actions.renameGroup), session count, context menu (Rename, Delete group, New session in this group -> onNewSession(group.id)). Draggable (kind 'group'); also a drop target (position 'inside' for sessions dropped on the header; 'before'/'after' for groups, decided by pointer Y relative to the header midpoint).
SessionRow.tsx: status dot in the status color (hollow ring if no status), name, muted subtitle = last path segment of cwd, attention indicator when runtime.attention is not null (pulsing dot + bell glyph with an aria-label like "Needs attention: permission"; colors via var(--attn-permission|--attn-done|--attn-idle)), an "exited" badge when runtime.run === 'exited', selected highlight. Click selects. Double-click or F2 renames inline via actions.renameSession. Context menu: Rename; Set status > (each status with its colored dot, plus "None"); Move to group > (each group, "No group", and "New group..." which creates a group then moves); Remove session (with in-UI confirm, NOT window.confirm which is disabled). Draggable (kind 'session'); drop target for sessions ('before'/'after' by pointer Y).
InlineEdit.tsx: props {value:string; onCommit(v:string):void; onCancel():void; ariaLabel:string}. Selects all on mount, Enter commits, Esc cancels, blur commits; uses validateName; shows the error text under the input and keeps editing when invalid. Commits only if the trimmed value changed.
ContextMenu.tsx: generic: props {x:number;y:number;items: MenuItem[]; onClose():void} where MenuItem = {label:string; onSelect?():void; danger?:boolean; disabled?:boolean; submenu?: MenuItem[]; swatch?: string}. Positioned at the cursor and clamped inside the viewport, arrow-key navigation, Enter activates, Esc and outside click close it, submenus open on hover/ArrowRight.
Drag and drop: native HTML5 DnD. Keep the current drag item in component state (do not rely on dataTransfer payload reading during dragover). On drop call computeDrop(drag, over, data); if it returns {type:'moveSession'} call actions.moveSession(sessionId, groupId, index); if {type:'reorderGroups'} call actions.reorderGroups(order). Show a thin drop indicator line before/after the hovered row and a highlight ring on a group header for 'inside'.
Accessibility: container role="tree", groups role="group" with aria-expanded, sessions role="treeitem" with aria-selected, every icon-only button has aria-label, visible focus ring, respect prefers-reduced-motion for the pulse animation.
